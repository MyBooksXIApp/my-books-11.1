## Get started

1. Open the download page above and choose **My Books 11.1 Installer.exe** from the release assets.
2. Run the installer and choose whether you are new to My Books or coming from an older version.
3. Open My Books and explore the Demo Account, create your own profile, or import your backup.
4. For a new profile, start in **My Calendar**: set up your paychecks and periods first. Then build out your funds, bills, credit, budget, and savings goals.

The **My Books 11.1 User Guide.pdf** is included with the release. It contains a quick start guide, detailed explanations of the controls, and step-by-step instructions with clickable navigation.

## Coming from My Books 11.0.2?

**Bring a backup copy. Keep your original installation.**

1. In 11.0.2, sign in and open your profile menu.
2. Choose **Export This Profile** or **Back Up Everything**. Save the **.aas** backup and remember its backup password.
3. In the 11.1 installer, choose the older-version option and select your backup, or use **Import Backup** on the 11.1 login screen later.
4. Enter the requested backup and original profile passwords, then review the transfer report before completing the import.

11.1 installs in its own folder. Importing a backup creates a copy for 11.1; it does not upgrade your original profiles in place. You can return to the older installation if needed.

Some features and record formats have changed. Review any import notices, including notes affected by length limits. **Routines are no longer tracked in 11.1**; the transfer report explains this when routine history is present.

## Saving your work

Use **Save and Quit** to keep your session changes. **Quit without saving** discards unsaved changes. Demo changes are temporary.

When My Access relocks, its working copy remains in memory so your edits can still be saved with the session. The whole-app lock also keeps your live session in memory and requires authentication to resume.

Keep regular **.aas backups** and store your recovery key somewhere safe. See the guide for the full backup, recovery, and security workflows.
